# Eddie Bauer Clone

## About Project

Eddie Bauer Clone is a responsive e-commerce web application inspired by the official Eddie Bauer website. The project was built as a collaborative team project during Masai School. Users can browse products, explore product details, and experience a modern online shopping interface.

## Project Workflow

1. User visits the homepage.
2. User browses available products.
3. User views detailed product information.
4. User adds products to cart.
5. User enters shipping details.
6. User proceeds through checkout flow.
